Full-Stack Architecture

Engineered for Low-End Android & Slow Connections

A resilient three-tier pipeline connecting shopkeeper smartphones to institutional lending APIs.

Layer 1: Presentation & Recording (Flutter Mobile Client)

Flutter 3.x · Riverpod · record ^5.2.1 · RTL Urdu

State-managed with Riverpod. Features WhatsApp-style live waveform recording, haptic feedback, bilingual English/Urdu with complete RTL layout rendering, and 150-second timeout tolerance for free-tier cloud wakeups.

Layer 2: Vernacular AI Pipeline (FastAPI Service)

FastAPI · Groq Whisper-v3 · Groq LLM · Bazaar Taxonomy

Groq Whisper-large-v3 speech-to-text combined with a specialized Pakistani bazaar vernacular LLM parser. Strict JSON Schema constraints eliminate hallucinations, and ambiguity detection triggers Roman Urdu clarification dialogues.

Layer 3: Ledger Store & Evidence Computer (Persistence & B2B API)

SQLite · Heuristic Scorer · X-User-Consent · REST API

ACID SQLite persistence storing confirmed entries and raw audio transcripts. Computes 30-day volatility (CV), cash buffer runway, and micro-loan sizing brackets. Exposes consent-gated endpoint /evidence-profile with cryptographic headers.

Trust & Data Integrity

The Zero-Hallucination Safeguard

In accounting, an AI hallucination is a catastrophic financial discrepancy. Karobar Saathi never guesses.

Ambiguity Detection Case

The "3000 Diye" Problem

A shopkeeper records: "3000 diye." (Gave 3000).
Did they pay a vendor? Give money to family? Pay rent? Settle a debt?

❌ Generic AI: Guesses "Expense: PKR 3,000" (Corrupts books)
✔️ Karobar Saathi: Flags entry_type: "unclear"
Conversational Clarification Prompt:

"Bikri ki amount kya hai ya ye paise kisko diye the?"

1. Strict Structural JSON Output

Leverages strict schema enforcement with fixed enum constraints: entry_type must be one of [sale, purchase, expense, withdrawal, unclear].

2. Human-in-the-Loop Confirmation

Every extracted transaction displays an editable confirmation sheet. The user can tweak category or amount with one tap before saving.

3. Spoken Audio Audit Trail

Original spoken audio transcripts are permanently bound to the ledger entry, creating an immutable forensic record for dispute resolution.

Fintech Engine

Converting Voice Notes into Underwriting Evidence

Microfinance banks don't have time to read thousands of ledger lines. We distill raw records into statistical credit signals.

1. Transaction Consistency Index

Active Days / 30

Proves operational stability. A merchant recording 26 out of 30 days demonstrates high discipline and continuous trade.

2. Sales Volatility (Coefficient of Variation)

CV < 20% = Low Risk

Evaluates week-over-week revenue variation to assess whether income is steady or subject to wild seasonal fluctuations.

3. Net Cash Buffer Runway

Net Cash / Daily Expenses

Calculates how many days of operating expenses are covered if revenue momentarily halts. Vital for loan safety.

Privacy by Design

Shopkeeper Sovereignty: Consent-Gated Architecture

We refuse predatory data harvesting. The shopkeeper retains absolute legal and technical ownership of their financial records.

🔐

Cryptographic Consent Gate

The Evidence API strictly requires an X-User-Consent: true header verified against real-time user database state.

⚡

One-Tap Instant Revocation

If the shopkeeper toggles consent off in the app, external API queries are immediately blocked with HTTP 403 Forbidden.

🛡️

Zero Third-Party Ad Tracking

No advertising SDKs, no behavioral trackers. Financial data is never shared or monetized with external commercial brokers.

LIVE PROTOCOL VERIFICATION (docs/VERIFICATION.md):

Revoking consent via PATCH /api/v1/evidence-profile/{user_id}/consent makes the endpoint return 403 consent_required even when the client supplies X-User-Consent: true.
